Sync between devices

Your progress can sync through a private gist in your GitHub account. Do this once on each device, using the same token:

  1. Create a fine-grained GitHub token. Name it “Language Drills sync”, set an expiration (for example 90 days or a year — GitHub reminds you before it runs out), and under Account permissions set only Gists to Read and write. Leave everything else at No access, tap Generate token and copy it.
  2. Paste it here and tap Connect. The token gives access to your gists and nothing else; you can revoke it on GitHub at any time.

Make it look like a standalone program

PC (Chrome/Edge): ⋮ menu → Cast, save and share → Install page as app (Edge: ⋯ → Apps → Install this site as an app). It opens in its own window and can be pinned to the taskbar. F11 = quick full screen.

Android (Chrome): ⋮ → Add to home screen, then open it from that icon.
